v1 이 놓친 낙상 4편(fall-13·14·25·28, risk 0.07~0.44)은 v3·v4 가 잡는다 — 트레이드오프다.

## 왜 이렇게 됐나

추가된 셋은 `fallen`(넘어진 채) 구간이 길고 많다 (UP_Fall 456 · MCFD 다수). 모델은 "수평 자세가 오래 지속 = fallen" 을 더 강하게 배웠고,
그게 침대에 누운 장면에 그대로 적용된다. `lying` 은 157개로 2.5% — 반대 증거가 부족하다.
**v2 에서 UP_Fall lying 102개를 학습에 넣고도 54개를 위험으로 판정**한 것과 같은 현상이다. 입력(정규화 좌표 + 속도)에 침대와 바닥을 가를 정보가 없다.

## 결론

- **배포 모델은 v1 유지.** 서비스 조건(연속 영상·오경보)에서 가장 낫다.
- 논문에는 **v4 의 환경 일반화(LOO)** 결과를 쓴다. 데이터 확장이 "낙상 Recall·환경 강건성" 을 올린 것은 사실이다.
- `lying` 문제는 데이터 양으로 풀리지 않는다 — 두 번 확인됐다 (v2 in-sample, v3/v4 외부셋). 남은 길은
  (a) OF-Synthetic `lying` 1,200 으로 비율 자체를 바꿔 보기, (b) 침대 ROI·진입 전이 같은 **맥락 입력**, (c) R1 을 "낙상 이벤트 후" 로만 발화하게 규칙 재설계 ([ISSUES.md](ISSUES.md) 1·4번).
- 모델 선택은 이제 **AI Hub + URFD 두 셋**으로 한다. 4장면에 과적합되는 위험이 절반으로 준다.
