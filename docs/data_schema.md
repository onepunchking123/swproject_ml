# 데이터 스키마 및 학습 계획

_VL.zip (Validation 라벨) 실측 분석 — 2026-09-20_

## 목표 재확인

낙상 탐지만이 아니라 **노약자가 혼자 있을 때 발생하는 위험 상황**을 감지한다.
낙상은 그중 가장 명확하고 라벨이 존재하는 사건이므로 첫 번째 대상이다.

| 단계 | 대상 | 라벨 |
|---|---|---|
| 1 | 낙상 | AI Hub 에 프레임 단위로 존재 |
| 2 | 장시간 미동 | 라벨 없음 — 규칙 + 맥락으로 파생 |
| 3 | 그 외 위험 (배회, 이상 자세, 장시간 부재) | 라벨 없음 — 향후 |

## 실측 구조

### 라벨 3종

압축을 풀면 `영상 / 이미지 / 센서` 로 나뉘고, 같은 장면에 대해 서로 다른 정보를 담는다.

| 종류 | 개수 | 단위 | 핵심 필드 |
|---|---|---|---|
| **영상** | 2,272 | 클립 1개 | `fall_start_frame`, `fall_end_frame`, 장면 메타 |
| **이미지** | 22,720 | 프레임 1장 | `bbox_location` |
| 센서 | 2,272 | 클립 1개 | 영상과 동일 메타 (센서 수치는 별도 CSV) |

### 영상 라벨 (클립 단위)

```json
{
  "metadata":   { "scene_id": "00504_H_D_N_C4", "scene_res": "3840 X 2160" },
  "scene_info": { "scene_loc": "병원", "scene_pos": "복도",
                  "scene_method": "bathchair", "scene_IsFall": "비낙상",
                  "scene_cat_name": "비낙상", "fall_type": "none",
                  "scene_length": 600, "cam_num": 4 },
  "actor_info": { "actor_id": "H", "actor_age": "adult2(중장년노년)", "actor_sex": "m" },
  "sensordata": { "fall_start_frame": 0, "fall_end_frame": 0 }
}
```

**`fall_start_frame` / `fall_end_frame` 이 가장 중요하다.** 낙상이 일어난 구간이
프레임 단위로 표시된다 (예: 286~346). 시계열 모델 학습에 그대로 쓸 수 있고,
**감지 지연(latency) 측정의 기준**이 된다.

낙상 구간은 **전부 정확히 60프레임 = 1.0초**다 (중앙값·최소·최대 모두 60).
데이터 구축 시 고정 길이로 라벨링한 것으로 보인다.

### 이미지 라벨 (프레임 단위)

```json
{ "metadata": { "file_name": "00504_H_D_N_C4_I007.JPG" },
  "bboxdata": { "bbox_location": "1473.39, 533.83, 1832.13, 1446.18" } }
```

**형식: `x1, y1, x2, y2` 절대좌표 (xyxy)**, 원본 3840×2160 기준.
샘플 200개 검사에서 이상 0건. YOLO 형식(`cx cy w h` 정규화)으로 변환이 필요하다.

클립당 10장씩 균등 추출되어 있다 (`_I001` ~ `_I010`).

## 분포 (Validation 기준)

```
클래스          전면낙상 776 · 후면낙상 576 · 측면낙상 352 · 비낙상 568
                → 낙상 1,704 (75%) : 비낙상 568 (25%)

장소            노인정/요양병원 1,056 · 집 608 · 병원 568 · 길거리 40
세부위치        병실 1,016 · 거실 568 · 복도 400 · 주방 112 · 화장실 104 · 평지 56 · 계단 16
보조기구        없음 1,848 · bathchair 168 · crutch 112 · senior_device 96 · cane 48
연령            중장년노년 1,640 (72%) · 청소년청년 632
낙상원인        중심을 잃고 1,104 · 걸려 296 · 미끄러져 264 · 부딪쳐 40
카메라          C1~C8 각 284개 (완전 균등)
피험자          24명 (A~Y)
고유 장면       284개 × 카메라 8대 = 2,272
```

### 이 수치가 말해주는 것

**1. Validation 만으로 학습이 가능하다.**
284개 고유 장면, 피험자 24명, 장소 4종. Training 436GB 없이도
초기 실험에는 충분하다. VS.zip 55GB 만 받으면 된다.

**2. 클래스 불균형이 있다 (낙상 75%).**
실제 환경은 정반대다 — 대부분의 시간은 비낙상이다. 학습 시 가중치 조정이
필요하고, 평가 지표를 Accuracy 가 아닌 **Recall/FPR** 로 봐야 하는 이유다.

**3. 도메인이 목표와 일치한다.**
노인정·요양병원 46%, 집 27%. 중장년노년 72%. 치매환자 모니터링과 맞다.

**4. 카메라가 완전 균등(각 284개)하다.**
카메라 독립성 실험을 설계하기 좋다 — 특정 카메라를 통째로 held-out 으로
빼서 "학습에 없던 각도에서의 성능"을 측정할 수 있다. AI Hub 베이스라인이
카메라별 모델 8개로 이 문제를 회피한 것과 정확히 대비된다.

**5. 피험자 24명으로 split 을 나눌 수 있다.**
클립 단위 split 보다 **피험자 단위 split** 이 더 엄격하다.
같은 사람의 다른 낙상이 train/test 에 갈리면 체형·습관이 누수된다.

## 학습 계획

### Stage 1 — 사람 검출 / 자세 추정

입력: 프레임 이미지 + BBOX 라벨 (22,720장)

```
VS.zip 영상 → 프레임 추출 → YOLOv11-pose 학습
                                ↓
                    사람 BBOX + 17 키포인트
```

BBOX 라벨이 있으므로 **검출 성능을 정량 평가**할 수 있다 (mAP50, mAP50-95).
키포인트 라벨은 없으므로 pose 는 COCO 사전학습 가중치를 그대로 쓰고,
낙상 판정 성능으로 간접 평가한다.

### Stage 2 — 낙상 판정 (시계열)

입력: Stage 1 이 뽑은 키포인트 시퀀스 + `fall_start/end_frame`

```
키포인트 (17×2) × N프레임 → 시계열 모델 → 낙상/비낙상
```

**라벨 활용 방식**: `fall_start_frame ~ fall_end_frame` 구간을 양성,
나머지를 음성으로 하는 **프레임 단위 라벨**을 만든다. 클립 단위 분류보다
정밀하고, 감지 지연을 측정할 수 있다.

비교 모델:

| 방법 | 역할 |
|---|---|
| 규칙 기반 (종횡비 + 몸통각도 + 하강속도) | 베이스라인, 학습 불필요 |
| 1D-CNN | 경량 대조 |
| LSTM / GRU | 표준 시계열 |
| BiLSTM + Attention | 성능 상한 |
| ST-GCN | 골격 그래프 구조 |

### Stage 3 — 미동 감지 (라벨 없음)

AI Hub 에 라벨이 없으므로 **규칙 + 맥락**으로 만든다.

```
트랙 유지된 사람 → 키포인트 변위 표준편차 < 임계값 → T초 지속 → 이벤트
```

단순 임계값만으로는 오탐이 폭발한다. 노약자는 정상적으로 오래 앉아있고 잔다.
조합할 맥락:

| 조건 | 근거 |
|---|---|
| 자세 (누움/앉음/서있음) | 바닥에 누운 채 미동 ≫ 소파에 앉아 미동 |
| 위치 (침대/소파 ROI vs 바닥) | `scene_pos` 가 힌트 — 병실/거실/화장실 |
| 시간대 | 새벽 침대 미동 = 정상, 낮 바닥 미동 = 이상 |
| **선행 낙상 이벤트** | 낙상 직후 미동 = 최고 위험 |

마지막 조건이 핵심이다 — Stage 2 와 결합하면 "넘어진 뒤 일어나지 못함" 을
탐지할 수 있고, 이것이 실제로 가장 위험한 시나리오다.

평가는 AI Hub #1 「독거노인 돌봄용 위험감지 데이터」(응급/주의/일상 6종 라벨)로
검증하는 방안을 검토한다.

## 데이터 분할 설계

**피험자 단위로 나눈다.** 클립 단위보다 엄격하다.

```
train : 피험자 17명 (약 70%)
val   :        4명 (약 15%)
test  :        3명 (약 15%)
```

추가 실험 — **카메라 held-out**:

```
train : C1~C6
test  : C7, C8       ← 학습에 없던 각도
```

AI Hub 베이스라인은 카메라별 모델이라 이 실험 자체가 불가능하다.
본 연구가 카메라 독립성을 주장하는 직접 근거가 된다.
